# Функции и рекурсия

## Задача 1. Быстрое возведение в степень

Нужно написать функцию, которая возводит число в степень `n`.
Количество действий должно быть пропорционально двоичному логарифму `n`.

**Файл:** [task1.cpp](task1.cpp).

### Через цикл — `step`

**Идея:** на каждом шаге степень делится пополам, а основание возводится в квадрат.
Если степень нечётная, результат дополнительно умножается на текущее основание.

### Через рекурсию — `recurse`

**Идея:** функция один раз вычисляет степень `n / 2`, сохраняет её и возводит результат в квадрат.
Для нечётной степени дополнительно умножает его на основание.
При `n = 0` возвращает `1`.

Оба способа работают за `O(log n)`. Степень должна быть неотрицательной,
а результат — помещаться в `long long`.
Программа выводит ответы обоих способов, каждый с новой строки.

**Ввод:**
```text
10 12
```

**Вывод:**
```text
1000000000000
1000000000000
```

## Задача 2. Наибольший общий делитель

Даны расходы двух друзей — натуральные числа `a` и `b`, не превышающие `10^9`.
Нужно рекурсивно найти наибольшую сумму, на которую делятся оба числа без остатка, — их НОД.

**Файл:** [task2.cpp](task2.cpp).

**Идея:** алгоритм Евклида — функция `gcd` заменяет пару `(a, b)` на `(b, a % b)`.
Когда второе число становится нулём, первое является НОД.

**Ввод:**
```text
9 12
```

**Вывод:**
```text
3
```

## Задача 3. Перекладывание ингредиентов

На первой салфетке лежат `n` ингредиентов: большие снизу, маленькие сверху.
Нужно перенести их на третью салфетку, используя вторую как вспомогательную.
За один ход можно переложить один верхний ингредиент. Большой на маленький класть нельзя.
Ингредиенты пронумерованы от `1` до `n` по возрастанию размера.

**Файл:** [task3.cpp](task3.cpp).

**Идея:** рекурсивный алгоритм «Ханойские башни» — функция `move` переносит
`n - 1` ингредиентов на вспомогательную салфетку, затем самый большой на целевую,
после чего переносит остальные поверх него. При `n <= 0` рекурсия останавливается.

Количество перемещений — `2^n - 1`. Каждая инструкция выводится с новой строки.

**Ввод:**
```text
2
```

**Ожидаемый вывод:**
```text
Ingredient 1 move from 1 to 2
Ingredient 2 move from 1 to 3
Ingredient 1 move from 2 to 3
```
