## Задание 1

**Условие:** описать алгоритм решения задачи согласно варианту «Алгоритм подготовки к экзамену».

**Файл:** `Задание1.txt`

**Краткое описание:** составлен пошаговый алгоритм подготовки к экзамену, включающий
пять основных этапов: инициализацию (определение даты, сбор материалов, оценка
знаний), планирование (расчёт времени, составление плана), основной цикл изучения
материала с регулярными перерывами, финальный контроль (проход по вопросам,
устранение пробелов, пробный тест) и завершение (отдых, сон, сбор вещей,
решение экзамена).
