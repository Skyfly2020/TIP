# Задача №7: Улитка

## Условие задачи:
Улитка ползёт по вертикальному шесту высотой h метров, поднимаясь за день на a метров, а за ночь спускаясь на b метров. На какой день улитка доползёт до вершины шеста?

## Способы решения:

* `Обыкновенный` — Самый простой код в один файл через обычные условия `if` и цикл `while`
* `Функциональный` — Код разбит на отдельные функции для проверки возможности подъёма и расчёта дней
* `Модульный` — Проект разделен на три файла: заголовочный файл `zaga.h`, реализация функций `7_3_1.cpp` и запуск в `main.cpp`
* `ООП` — Решение через ООП с использованием класса `Snailn`
