# Задача №5: Электронные часы

## Условие задачи:
Электронные часы показывают время в формате h:mm:ss, то есть сначала записывается количество часов, потом обязательно двузначное количество минут, затем обязательно двузначное количество секунд. Количество минут и секунд при необходимости дополняются до двузначного числа нулями.

## Способы решения:

* `Обыкновенное` — Самый простой код в один файл через обычные условия `if`
* `Функциональное` — Код разбит на отдельные функции для подсчета часов, минут и секунд
* `Модульное` — Проект разделен на три файла: заголовочный файл `zaga.h`, реализация функций `5_3_1.cpp` и запуск в `main.cpp`
* `ООП` — Решение через ООП с использованием класса `Clock`
