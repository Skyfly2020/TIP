# Решение задач 4-мя разными способами

## Способы решения:
1. **Обычный** — весь код написан просто в один файл внутри `main`.
2. **Через функции** — базовая логика вынесена в отдельные функции.
3. **Разделение по файлам** — код разбит на `.h` заголовок и `.cpp` файлы.
4. **ООП** — решение оформлено через классы (`class`)
