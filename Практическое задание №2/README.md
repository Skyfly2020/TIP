## Задача 3. Убрать условный оператор «Если»

Дан фрагмент с ветвлением: при `A = 0` присвоить `B = 2`, иначе `B = 1`.
Переменная `A` принимает только `0` или `1`.

Требуется убрать условный оператор, не используя другие условные конструкции.

**Идея:** ветвление заменяется арифметикой — `B = 2 - A`.

## Задача 4. Слияние двух упорядоченных массивов за один цикл

Даны два массива `A[a]` и `B[b]`, упорядоченные по возрастанию.
Нужно за один цикл от `1` до `a + b` вывести значения обоих массивов
в порядке возрастания — как если бы они были объединены и отсортированы.

**Идея:** два курсора `i` и `j` указывают на текущие элементы массивов.
На каждом шаге выводится меньший из них, после чего соответствующий курсор
сдвигается вперёд. Условия `i < a` и `j >= b` защищают от выхода за границы.

## Задача 5. Найти пропущенное число за один цикл

Дан неупорядоченный массив из `n` различных чисел — все числа от `0` до `n`
кроме одного `j`. Нужно найти `j` за один проход по массиву.

**Идея:** сумма всех чисел от `0` до `n` равна `n * (n + 1) / 2`.
Вычитая из неё сумму элементов массива, получаем пропущенное число.
Порядок элементов не важен.
